# 탐지 내역 내보내기

1. 검사 완료 후 탐지 내역 이동
2. 일부 항목만 저장할 경우 체크박스 선택
3. 기존 다운로드 버튼인 엑셀 저장 선택
4. 저장 창에서 Excel 또는 CSV 선택

선택 항목이 없으면 전체 탐지 내역 저장. 검색과 화면 필터는 전체 저장 범위를 변경하지 않음.
같은 게시글의 제목과 본문 및 댓글 근거는 엑셀에서 항목별로 구분.

Excel 열: 항목 ID / 구분 / 탐지 유형 / 게시글 주소 / 탐지 원문 / 위치 / 출처 / OCR 추출문 / 검토 상태 / 검토 메모 / 검토 시각 / 탐지 시각

첫 행 고정 및 열 필터 지원. 원문과 OCR 문구는 수식으로 실행되지 않는 텍스트로 저장.
검토 상태는 저장 시점의 검토 기록 반영. CSV는 기존 고정 열 형식 유지.
엑셀 셀당 32767자 초과 시 저장 중단 및 안내. 긴 원문은 CSV 또는 원본 JSON 사용.
