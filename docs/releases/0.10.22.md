# Chickadee Studio 0.10.22

- 앱 내부의 마우스 커서를 작은 Chickadee 로고로 변경했습니다.
- 필터 초기화, CSV 저장, 결과 불러오기 버튼을 아이콘으로 간결하게 표시합니다. 마우스를 올리면 기능 이름을 확인할 수 있습니다.
- 아이콘 버튼의 접근성 이름과 기존 동작은 유지됩니다.
- 탐지 결과 체크박스의 클릭 영역을 넓혀 주변 여백을 눌러도 선택되도록 개선했습니다.
- 선택 도구막대의 색상과 버튼을 정리하고 펼침·접힘 애니메이션을 추가했습니다.

Windows ZIP and SHA-256 checksum are published after packaged-app verification passes.
