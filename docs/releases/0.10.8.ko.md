# 0.10.8

[한국어](0.10.8.ko.md) | [English](0.10.8.md)

- Windows 실행 파일에는 치카비 캐릭터 아이콘만 적용하고, Electron 원본 런타임의 버전·제작사 등 파일 속성을 유지합니다. 빌드에서 원본·아이콘·편집 도구와 최종 실행 파일의 SHA-256을 검증합니다.
- 탐색기의 EXE 아이콘과 앱 화면의 이름·로고·디자인을 유지합니다.
- 한국어 OCR·ML 모델, 결과 JSON·CSV 형식, Groq 사용 한도를 유지합니다. 인증서 설치나 Windows 보안 설정 변경을 수행하지 않습니다.
