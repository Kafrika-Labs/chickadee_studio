# Release v0.10.18

[한국어](0.10.18.ko.md) | [English](0.10.18.md)

## Notification

- Extract the entire ZIP into a new folder and run `Chickadee.exe`. Keep the executable and its `resources` folder together.
- If Windows app control blocks `Chickadee.exe`, run `ChickadeeRuntime.exe` in the same folder.
- This build uses an alpha release of Electron (**46.0.0-alpha.1**) to address Node2Shell (CVE-2026-111497).

## What's New

### Security and runtime

- Updated Electron to **46.0.0-alpha.1** and Playwright to **1.64.1** for Node2Shell (CVE-2026-111497)
- Both bundled Node.js runtimes are now **24.22.1**
- Migrated encrypted notification settings to Electron 46's asynchronous secure storage API, including its decryption result object

### Evidence review

- Simplified evidence cards with white backgrounds, thin separators and restrained corners
- Removed nested colored boxes and the thick quotation border
- Moved screenshot enlargement beside its caption
- Replaced the colored images for Save note and Mark unreviewed with the line icons used by other menus

### Interface and guide

- Updated the user guide and screenshots
- Refined view transitions, app icons and HTTP activity labels

### Build and distribution

- Windows builds reuse the installed official Electron distribution without its demo app
- Kept executable and ASAR integrity verification
- Added support for separate Python environments and output directories
- App updates and model downloads now use the transferred official repository, `Kafrika-Labs/chickadee_studio`
- Existing model configuration and weight checksums are retained
