# 0.10.15

[한국어](0.10.15.ko.md) | [English](0.10.15.md)

- Remove Laya's 12-context per-scan cap. Analyze all nonempty collected text/findings, reusing identical-text results.
- Load the CPU model once and process small batches, showing completed/total counts and preserving finished results on cancellation.
- Remove RF-score/context-type exclusions from Laya. Processing uses the bundled local model without added API calls/costs.
- Set new-installation deadlines to 1,800 seconds while retaining saved user settings.
- Preserve flat navigation, newest/oldest sorting, Korean OCR and visual classification.

Extract the entire ZIP into a new folder and run Chickadee.exe. If Windows app control blocks it, run ChickadeeRuntime.exe in the same folder.
