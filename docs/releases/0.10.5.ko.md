# 0.10.5

[한국어](0.10.5.ko.md) | [English](0.10.5.md)

- 수집 중 로그인 화면으로 이동하면 로그인 안내를 표시하고 검사를 기다립니다. 별도 로그인 창에서 인증한 뒤 원래 페이지의 검사를 재개할 수 있습니다. 로그인 대기 시간은 검사 제한시간에서 제외합니다.
- 일반적인 로그인 주소로의 HTTP·스크립트 이동과 비밀번호 입력 화면을 감지합니다. 로그인 쿠키는 이번 검사에서만 사용하며, 건너뛴 페이지는 인증 필요로 기록합니다. 팝업·브라우저 저장소 기반 인증과 일부 비표준 로그인 주소는 지원되지 않을 수 있습니다.
- 로그인 모달의 문구와 버튼을 간결하게 정리했습니다. 도움말은 내용을 가리지 않도록 아래로 펼쳐지며, 검사 재개는 재생 아이콘으로 표시합니다. 수집한 사이트 이름과 파비콘을 표시하고 정보가 없으면 도메인·기본 아이콘을 사용합니다.
- 알림·저장 완료·가이드·미리보기 모달을 차콜 색상으로 통일했습니다.
- HTTP 통신 기록에서 상태 코드는 작은 색상 뱃지로, GET 등 메서드는 색상 텍스트로 구분합니다.
- 진행 기록의 오류·경고·일시정지 등 아이콘과 광고 분류 아이콘의 크기·정렬을 개선했습니다.

이번 배포는 **미서명 Windows x64 ZIP**입니다. macOS 배포 파일은 포함하지 않습니다.
