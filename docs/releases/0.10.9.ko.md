# 0.10.9

[한국어](0.10.9.ko.md) | [English](0.10.9.md)

- 기존 디자인과 한국어 OCR 모델을 유지하고 ML, Laya, OCR 처리 통계를 표시합니다.
- Groq는 광고 의심 근거부터 검토하며 같은 사이트의 추가 확인과 누적 예산 제한을 유지합니다.
- 원문, URL, 스크린샷과 미검토 수를 포함한 HTML 및 Markdown 리포트를 저장합니다.
- 투명하거나 화면 밖에 있는 요소의 스크린샷 확대를 수정했습니다.
- 반복 이미지의 OCR 캐시를 재사용하고 작성, 수정, 삭제 링크는 자동 탐색에서 제외합니다.
- 치카비 아이콘과 공식 런타임 속성, ASAR 무결성 검증을 유지합니다.
