# 0.10.11

[한국어](0.10.11.ko.md) | [English](0.10.11.md)

- 한국어 Laya 학습 모델과 독립 CPU 실행 파일을 Windows 실행본에 포함했습니다. 별도 모델·Python 설치 없이 OCR → ML → Laya 분석을 사용합니다.
- 학습 가중치를 한 번만 읽도록 배포 구성을 줄이고 첫 로딩 제한을 남은 검사 시간 안에서 최대 120초로 조정했습니다.
- 일부 페이지를 확보한 뒤 탐색이 중단되면 오류와 수집한 내용을 ‘일부 결과’로 보존합니다.
- 완료 알림을 놓친 화면은 저장된 검사 기록을 확인해 결과를 복구합니다. 완료 후 검사 구성에서 탐지 내역으로 이동합니다.
- 검사 실패의 오류 로그와 진행 기록을 결과 폴더에 저장합니다.
- 투명 PNG 배경과 작은 배너 전처리를 개선했습니다. 문자 영역 미검출과 신뢰도 미달을 구분합니다.
- Windows 이벤트 루프 초기화의 일시적인 오류만 제한적으로 재시도하며 검사 작업 자체를 재실행하지 않습니다.
- 테스트 사이트 제작 안내문이 ML 광고 후보로 반복되는 경우를 보정했습니다.
- 기존 디자인, 한국어 OCR·RF 가중치와 Groq 사용 한도를 유지합니다.

Windows x64 ZIP 전체를 압축 해제한 뒤 Chickadee.exe를 실행하세요. macOS용 실행본은 포함하지 않습니다.
