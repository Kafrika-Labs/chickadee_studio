# 0.10.5

[한국어](0.10.5.ko.md) | [English](0.10.5.md)

- Login redirects during collection now pause the scan and prompt for authentication in a separate window, then resume the original page. Login waiting is excluded from scan deadlines.
- Detect common HTTP/script login redirects and password screens. Cookies are used only for this scan; skipped pages are recorded as requiring authentication. Popup/browser-storage authentication and some unusual login paths may not be supported.
- Simplify login-modal copy/buttons. Expand help below content and show resume with a play icon. Display collected site names/favicons, falling back to the domain/default icon.
- Unify notification, save-complete, guide and preview modals in charcoal.
- Show HTTP status as small colored badges and methods such as GET as colored text.
- Improve event and advertising-category icon size/alignment.

This release is an **unsigned Windows x64 ZIP**, without macOS assets.
