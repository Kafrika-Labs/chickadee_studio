# 0.10.15

[한국어](0.10.15.ko.md) | [English](0.10.15.md)

- Laya의 검사당 12개 문맥 제한을 제거했습니다. 수집한 모든 비어 있지 않은 텍스트와 탐지 항목을 분석하고, 같은 문구는 결과를 재사용합니다.
- CPU 모델을 한 번 불러온 뒤 작은 묶음으로 이어서 처리합니다. 완료 수·전체 수를 표시하며, 중단되더라도 이미 완료한 결과는 보존합니다.
- RF 점수나 문맥 종류에 따라 Laya 분석에서 제외하던 조건을 제거했습니다. 추가 API 호출이나 비용 없이 동봉한 로컬 모델로 처리합니다.
- 새 설치의 기본 제한시간을 1,800초로 조정했습니다. 기존에 저장한 사용자 설정은 유지합니다.
- 기존 평면 경로 목록, 최신순·오래된순 정렬, 한국어 OCR과 사진 분류 구성을 유지합니다.

ZIP 전체를 새 폴더에 압축 해제한 뒤 Chickadee.exe를 실행하세요. Windows 앱 제어로 차단되면 같은 폴더의 ChickadeeRuntime.exe를 실행하세요.
