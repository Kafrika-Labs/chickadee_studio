# 0.10.6

[한국어](0.10.6.ko.md) | [English](0.10.6.md)

- Show OCR only on the image processing path. Text goes directly to ML; no-image runs do not mark OCR completed.
- Use Korean PaddleOCR and text/image ML. Laya weights are not included in this release's default package.
- Explicitly installed and validated local Laya bundles can review up to 12 contexts. Default packages do not use Laya or automatically make paid calls/download models.
- Discard OCR workers on cancellation/timeout so late responses cannot attach to the next image.
- Preserve 0.10.5 design/login behavior, result JSON/CSV formats and Groq call/token limits.
- Save additional advertising-context observations to `result_extra.json`, without declaring illegality. Document paths at the start of quick start.
- Support `--groq-env-file` to read `GROQ_API_KEY` from a user-selected external file. Loading a key or starting the app does not send paid requests.
