# 0.10.13

[한국어](0.10.13.ko.md) | [English](0.10.13.md)

- 페이지 이미지 수집 기준을 서로 다른 원본 50개·관측 위치 500곳으로 조정했습니다. 같은 아이콘이 반복돼 뒤의 게시글 이미지가 제외되던 문제를 수정했습니다. 전체 수집 용량과 처리 시간 제한은 유지합니다.
- 이미지 수집 과정에서 확인한 첨부파일은 문서처럼 다시 방문하지 않습니다. 인라인 표시·다운로드 주소가 다른 동일 이미지도 처리 결과를 재사용합니다.
- 이전 릴리스와 코드·의존성이 같은 Laya CPU 실행 환경은 검증한 원본을 재사용해 빌드 시간을 줄입니다. 모델과 실행 파일을 동봉하며 사용자 설치는 필요하지 않습니다.
- 한국어 추가 학습 OCR, OCR 배지, 경로 접기, 최신순 정렬과 Windows 호환 실행기를 유지합니다.

ZIP 전체를 새 폴더에 압축 해제한 뒤 Chickadee.exe를 실행하세요. Windows 앱 제어로 차단되면 같은 폴더의 ChickadeeRuntime.exe를 실행하세요.
