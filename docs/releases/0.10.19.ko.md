# Release v0.10.19

[한국어](0.10.19.ko.md) | [English](0.10.19.md)

## 안내

- ZIP 전체를 새 폴더에 풀고 실행 파일과 `resources` 폴더를 함께 유지하세요
- 보안 패치된 Node.js를 포함한 Electron 46.0.0-alpha.1을 유지합니다
- AI는 본인의 API 키와 별도 API 과금이 필요하며 실제 키는 배포본에 포함하지 않습니다

## 변경 사항

### AI 연결

- Groq·OpenAI(GPT)·Anthropic(Claude) 선택과 모델·사용량 한도 설정
- API 키는 세션 메모리에만 보관하고 제공자 변경 시 새 키 요구
- 제공자별 로고와 앱 내부 드롭다운 적용
- 로컬 HTTP 모의 서버로 근거 조회·JSON 응답·오류 처리 검증, 실제 OpenAI·Claude 인증과 과금은 미검증

### 언어 및 설정

- 첫 실행 기본 언어를 한국어로 지정하고 한국어·영어 전환 지원
- 언어 변경을 즉시 적용하고 재실행 후 선택 유지
- 언어 선택 칸 축소 및 실행 환경 제목·상세 내용 정렬

### 화면

- 사이드바 선택 배경에 작은 라운드 적용
- 상단 결과 폴더 버튼 제거 및 검사 실행 버튼 우측 정렬
- API 키 입력창을 열면 닫기 아이콘 표시
