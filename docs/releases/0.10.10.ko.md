# 0.10.10

[한국어](0.10.10.ko.md) | [English](0.10.10.md)

- 설치한 한국어 Laya 모델을 앱에서 자동으로 읽어 OCR과 ML 다음 단계에 연결합니다.
- 외부 Python 실행 환경에서도 패키지에 포함한 Laya 워커를 실행합니다.
- 모델 텐서를 직접 연결해 CPU 추론의 메모리 사용을 줄였습니다.
- Laya의 일부 처리 상태를 통계 화면에 정확히 표시합니다.
- 기존 화면 디자인, 한국어 OCR, RF 모델과 Groq 사용량 한도를 유지합니다.

Laya 가중치와 실행 환경은 [한국어 문맥 모델 팩](https://github.com/Kafrika-Labs/chickadee_studio/releases/tag/laya-ko-v1)으로 별도 설치합니다.
