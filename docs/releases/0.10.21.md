# Chickadee Studio 0.10.21

## 변경 사항

- 설정에 인증 메뉴를 추가했습니다. 운영하는 HTTPS 사이트의 경로·유효 시간에 한정된 검사 토큰을 생성하고 등록할 수 있습니다. 토큰은 현재 앱 세션에만 보관되며, 사이트 WAF 허용 규칙은 운영자가 별도로 등록해야 합니다.
- 실패한 검사 기록을 누르면 HTTP 상태와 저장된 오류를 확인할 수 있습니다.
- 일반 설정·단축키·실행 환경·예약 활성화 변경에 명시적인 저장 동작을 적용했습니다.
- 탐지 필터에 취소·저장을 추가하고 선택 개수 표기를 제거했습니다.
- 탐색 그래프를 중앙 정렬하고 END 연결선을 바깥 곡선으로 표시합니다. 노드 상세는 닫기 가능한 모달로 제공합니다.
- AI 분석 정보·모델 점수·스크린샷 확대·실행 내역 화면을 정리했습니다.
- 화면 전환, 가이드 탭, 펼침 영역, 알림에 애니메이션을 적용했습니다. 운영체제의 동작 줄이기 설정을 따릅니다.
- 인증 가이드를 추가하고 시작 화면 이미지를 갱신했습니다.

## Notes

Site authentication sends scoped headers only for authorized HTTPS GET/HEAD requests. It does not automatically configure or bypass a site's WAF. Server allow rules must be managed separately. Tokens are not persisted across application restarts.

Windows ZIP and SHA-256 checksum are published after packaged-app checks pass.
