# Release v0.10.20

[한국어](0.10.20.ko.md) | [English](0.10.20.md)

## Changes

- Combined result type, review and sort options into one filter icon; placed reset and CSV export on the right.
- Adjusted result and path search widths and improved the AI analysis card layout for status, scores and details.
- Translated scan progress, model names and Laya availability messages in English mode while preserving source evidence and unknown diagnostics.
- Added phonetic, initial-consonant, Korean keyboard, digit substitution and Unicode keyword variants. Evidence includes the original text, interpretation and transformation method.
- Retained promotional-context requirements and prevention/editorial exclusions. Domain and cloaking scoring rules are outside this release.

Extract the entire ZIP into a new folder and keep the executable and `resources` together.
