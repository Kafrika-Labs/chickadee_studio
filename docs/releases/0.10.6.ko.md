# 0.10.6

[한국어](0.10.6.ko.md) | [English](0.10.6.md)

- 이미지가 있을 때만 OCR을 수행하는 흐름을 검사 구성에 표시합니다. 텍스트는 ML로 바로 전달하고 이미지가 없으면 OCR을 완료로 표시하지 않습니다.
- 한국어 PaddleOCR와 문자·이미지 ML을 사용합니다. Laya 가중치는 기본 배포본에 포함하지 않습니다.
- 검증한 로컬 Laya 묶음을 명시적으로 설치한 환경에 한해 최대 12개 문맥을 추가 검토하는 연결을 제공합니다. 기본 배포본은 미적용이며 유료 호출이나 모델 다운로드를 자동 수행하지 않습니다.
- OCR 취소·시간 초과 시 작업 프로세스를 폐기해 이전 이미지의 늦은 응답이 다음 이미지의 근거로 붙는 문제를 방지합니다.
- 0.10.5의 디자인·로그인 기능과 기존 `result.json`·CSV 형식을 유지합니다. Groq의 호출·토큰 한도도 유지합니다.
- 추가 광고 문맥 관측값을 별도 `result_extra.json`에 기록합니다. 검토 후보를 불법 확정으로 바꾸지 않으며 파일 경로를 빠른 실행 안내 첫 장에 명시합니다.
- `--groq-env-file`로 사용자가 지정한 외부 설정 파일의 `GROQ_API_KEY`를 읽을 수 있습니다. 키를 읽거나 앱을 시작하는 것만으로 유료 요청을 보내지 않습니다.
