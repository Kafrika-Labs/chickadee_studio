# Release v0.10.20

[한국어](0.10.20.ko.md) | [English](0.10.20.md)

## 변경 사항

- 결과 목록의 분류·검토·정렬 메뉴를 필터 아이콘 하나로 통합하고 초기화·CSV 저장을 오른쪽에 배치했습니다.
- 결과·경로 검색창의 너비를 조정하고 AI 분석 카드의 상태·점수·상세 정보 배치를 개선했습니다.
- 영문 모드에서 검사 진행 메시지, 모델명과 Laya 미적용 사유를 번역합니다. 원문 근거와 알 수 없는 진단 메시지는 보존합니다.
- 변형 키워드 탐지에 발음 변형, 초성, 한영 자판, 숫자 치환과 유니코드 정규화를 추가했습니다. 근거에 원문·해석·변형 방식을 표시합니다.
- 기존 권유 문맥 확인과 예방·보도 문맥 제외 조건을 유지합니다. 도메인·클로킹 점수 규칙은 이번 변경에 포함하지 않습니다.

ZIP 전체를 새 폴더에 압축 해제하고 실행 파일과 `resources` 폴더를 함께 유지하세요.
