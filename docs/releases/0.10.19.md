# Release v0.10.19

[한국어](0.10.19.ko.md) | [English](0.10.19.md)

## Notification

- Extract the entire ZIP into a new folder; keep the executable and `resources` together
- This release retains Electron 46.0.0-alpha.1 with the patched Node.js runtime
- AI providers require your own API key and separate API billing; no real API keys are bundled

## What's New

### AI connections

- Choose Groq, OpenAI (GPT), or Anthropic (Claude), with editable models and usage limits
- Keep keys in session memory and require a new key when switching provider
- Add provider logos and an app-styled selection menu
- Verify tool calls, final JSON and error handling against local HTTP simulations; live OpenAI/Claude credentials and billing were not tested

### Language and settings

- Start in Korean by default and switch between Korean and English in settings
- Apply language changes immediately and preserve the selection after restart
- Compact the language selector and organize runtime details beneath a separate heading

### Interface

- Add subtle rounding to sidebar selections
- Remove the top-bar results-folder button and align scan controls to the right
- Use a close icon when the API key editor is open
