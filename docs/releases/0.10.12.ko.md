# 0.10.12

[한국어](0.10.12.ko.md) | [English](0.10.12.md)

- 검증한 한국어 OCR 인식 모델을 실행본에 포함했습니다. 실제 한국어 문자 영역 20곳의 소규모 점검에서 기존 30자 오류가 10자로 줄었으며, 전체 이미지 처리와 앱의 한글 근거 표시를 함께 검증합니다.
- 표준 모드에서 OCR을 기본으로 켜고, 여유 메모리에 따라 이미지 한도가 10장으로 줄어들던 동작을 수정했습니다. 서로 다른 이미지 최대 1,000장, 수집 원본 총 100MB를 기준으로 처리합니다. 시간·수집 한도에 도달한 항목은 미처리로 기록합니다.
- 같은 이미지의 분석과 원본 저장을 재사용하며, 발견한 페이지·위치를 함께 보존합니다. 게시글·댓글 이미지를 우선 수집하고 작은 탐색 아이콘을 사진 분류에서 구분합니다.
- OCR 단계는 이미지 처리와 문자 추출 상태를 표시합니다. 탐지 목록과 상세 화면의 OCR 배지는 실제 추출 문구를 근거로 사용한 항목에 표시합니다.
- 탐색 경로를 URL의 `/` 단위로 접고 펼칠 수 있습니다. 검색 시 일치하는 하위 경로를 표시합니다.
- 탐지 내역은 발견 시각 기준 최신순으로 표시하며 오래된순을 선택할 수 있습니다.
- 로그인·회원가입 주소를 게시글 링크 탐색에서 제외하고, 로그인 상태가 바뀌지 않는 재시도를 두 번으로 제한해 반복 요청을 막았습니다. 보호된 게시글의 정상 로그인 재개는 유지합니다.
- 기존 화면 구성, 선택한 사용자 설정, 결과 입출력 형식과 Groq 비용 한도를 유지합니다.
- Windows 앱 제어 정책이 적용된 PC를 위해 공식 Electron 원본을 수정하지 않은 호환 실행기를 함께 제공합니다. 같은 앱·모델을 실행하며 보안 설정을 변경하지 않습니다. 기존 치카비 실행 파일과 앱 창 아이콘은 유지합니다.

Windows x64 ZIP 전체를 압축 해제한 뒤 Chickadee.exe를 실행하세요.
