# 0.10.16

[한국어](0.10.16.ko.md) | [English](0.10.16.md)

- 로컬 AI 분석 결과를 한 줄 목록으로 정리했습니다. 문구 검색, 유사 신호·웹페이지 문구·이미지 문구 필터, 20개 단위 페이지 이동을 지원합니다. 유사 신호가 있는 항목을 먼저 표시하며, 항목을 펼치면 전체 원문과 모델별 분석을 볼 수 있습니다.
- AI 분석·리포트 화면의 다크 배경, 글자 대비, 통계 표의 마우스 강조색을 정리했습니다. 상단 탭은 흰색 배경을 유지하고 카드의 모서리와 버튼 간격을 다듬었습니다.
- 검토 요약의 수집·완료·미검토 수치를 색으로 구분하고, 분석 필터에 아이콘을 추가했습니다.
- 탐지 근거의 검토 상태·작업 메뉴를 상단으로 옮겨 유형 뱃지가 본문을 밀어내는 문제를 줄였습니다. 항목 ID는 기술 정보에서 확인할 수 있습니다.
- 탐지 내역의 분류 탭을 선택 메뉴로 묶고 검색·분류·검토·정렬을 일정한 순서로 배치했습니다. 좁은 화면에서는 검색과 필터를 두 줄로 정렬합니다.
- 탐지 근거 상단 작업 메뉴의 항목과 아이콘이 겹치거나 잘리는 문제를 수정했습니다.
- 일반 설정에 명시적인 저장 버튼을 추가했습니다. 자동 저장도 계속 지원합니다.
- 탐지 내역·탐색 경로·진행 기록의 빈 화면 안내 위치를 맞추고 Laya 전용 아이콘을 적용했습니다.
- 이전 미배포 변경을 포함합니다: 평면 탐색 경로 목록과 최신순·오래된순 정렬, Laya의 검사당 12개 문맥 제한 제거와 중복 문구 결과 재사용, 새 설치의 기본 제한시간 1,800초.

ZIP 전체를 새 폴더에 압축 해제한 뒤 Chickadee.exe를 실행하세요. Windows 앱 제어로 차단되면 같은 폴더의 ChickadeeRuntime.exe를 실행하세요.
