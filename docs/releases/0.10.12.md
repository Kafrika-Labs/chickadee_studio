# 0.10.12

[한국어](0.10.12.ko.md) | [English](0.10.12.md)

- Bundle the validated Korean OCR recognizer. A small audit of 20 real Korean text regions reduced errors from 30 to 10 characters; also validate full-image processing and Korean evidence display.
- Enable OCR by default in Standard mode and remove the memory-based reduction to ten images. Process up to 1,000 unique images and 100 MB of originals, marking time/collection-limited items unprocessed.
- Reuse identical-image analysis/storage and preserve page/location observations. Prioritize post/comment images and distinguish small navigation icons in visual classification.
- Show image-processing/text-extraction state in OCR. OCR badges identify findings actually supported by extracted text.
- Expand/collapse navigation paths by URL slash segments; search shows matching descendants.
- Default findings to newest first, with oldest-first selection.
- Exclude login/sign-up URLs from post discovery and limit unchanged-login retries to two, retaining authenticated-post resume.
- Preserve layout, user settings, output formats and Groq limits.
- Include an unmodified official Electron compatibility launcher for PCs with Windows app-control policies. It runs the same app/models without changing security settings, preserving existing app/executable icons.

Extract the entire Windows x64 ZIP and run Chickadee.exe.
