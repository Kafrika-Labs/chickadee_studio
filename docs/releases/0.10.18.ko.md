# Release v0.10.18

[한국어](0.10.18.ko.md) | [English](0.10.18.md)

## 알림

- ZIP 전체를 새 폴더에 압축 해제한 뒤 `Chickadee.exe`를 실행하세요. 실행 파일과 `resources` 폴더를 함께 유지해야 합니다.
- Windows 앱 제어 정책으로 `Chickadee.exe`가 차단되면 같은 폴더의 `ChickadeeRuntime.exe`를 실행하세요.
- Node2Shell(CVE-2026-111497) 대응을 위해 이 빌드는 Electron 알파 버전(**46.0.0-alpha.1**)을 사용합니다.

## 새로운 기능

### 보안과 런타임

- Node2Shell(CVE-2026-111497) 대응을 위해 Electron을 **46.0.0-alpha.1**, Playwright를 **1.64.1**로 업데이트
- 두 내장 Node.js 런타임을 **24.22.1**로 통일
- Electron 46의 비동기 보안 저장소 API에 맞춰 알림 설정의 암호화·복호화 갱신

### 근거 검토

- 탐지 근거를 흰 배경, 얇은 구분선, 절제된 모서리로 정리
- 원문 왼쪽 강조선과 중첩된 색상 박스 제거
- 스크린샷 확대 버튼을 제목 옆으로 이동
- ‘메모 저장’·‘미검토로 변경’을 다른 메뉴와 같은 선형 아이콘으로 통일

### 화면과 가이드

- 사용 가이드와 안내 이미지 갱신
- 화면 전환, 앱 아이콘, HTTP 활동 표시 개선

### 빌드와 배포

- Windows 빌드에서 설치된 공식 Electron 런타임을 재사용하고 기본 데모 파일 제외
- 기존 실행 파일·ASAR 무결성 검증 유지
- 별도 Python 환경과 출력 폴더 지원
- 앱 업데이트와 모델 다운로드 주소를 이전된 공식 저장소 `Kafrika-Labs/chickadee_studio`로 변경
- 기존 모델 설정·가중치 체크섬 유지

**전체 변경 내역**: [v0.10.16...v0.10.18](https://github.com/Kafrika-Labs/chickadee_studio/compare/v0.10.16...v0.10.18)
